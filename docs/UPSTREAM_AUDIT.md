mpvRx's build manifest includes Compose/Material 3, Room, Koin, Kotlin serialization, OkHttp, multiple native mpv distributions and numerous video/network features. Its inventory includes app icons, Android vector resources, artwork, shader collections (including Anime4K/hdr-toys), and website assets. None are necessary to this Windows music milestone; none were copied.

PixelPlayer's inventory includes Telegram database entities, repository/client/cache/proxy paths, channel search/dashboard/auth screens, Android icons and a branded SVG under `assets`. Its build manifest declares a TDLib dependency and Telegram API build-configuration fields. These observations establish platform/dependency boundaries; they are not permission to reuse the code. The current license remains the conservative exclusion rule even where its README mentions earlier MIT contributions.

Auralis dependencies are selected for Windows rather than transplanting either Android dependency graph. All cover placeholders are generated by Auralis's own painter. UI typography uses the Windows-installed Segoe UI font; no Microsoft font file is distributed. Material icons come from Flutter under Flutter's notice terms. Test previews load installed Windows fonts only for rendering.
